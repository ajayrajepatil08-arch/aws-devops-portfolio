# \# AWS DevOps Portfolio Project

# 

# \## About

# A simple portfolio website built and containerized using Docker.

# 

# \## Technologies Used

# \- HTML and CSS

# \- Git and GitHub

# \- Docker

# \- GitHub Actions

# 

# \## What I Learned

# \- Created and hosted a website using GitHub Pages.

# \- Built a Docker image using a Dockerfile.

# \- Ran the website inside a Docker container.

# \- Created a CI workflow using GitHub Actions.

# \- Automated Docker image builds on every push.

# 

# \## How to Run

# 1\. Clone this repository.

# 2\. Build the Docker image:

# &#x20;  docker build -t my-portfolio .

# 3\. Run the container:

# &#x20;  docker run -d -p 8080:80 --name my-portfolio-container my-portfolio

# 4\. Open http://localhost:8080 in your browser.
